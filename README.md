# Aishwarya — Midnight Blossom Portfolio

A responsive personal portfolio with a pink-first Midnight Blossom theme and a switch to Midnight Blue Blossom.

## Features
- Pink blossom theme by default; blue blossom theme available through the header switch
- Theme preference saved in browser local storage
- Animated falling flower petals (respects reduced-motion preferences)
- Responsive navigation and layout
- Profile photograph and portfolio sections for education, skills, internships, projects, certifications, achievements, activities, and contact

## Run locally
1. Download and extract this folder.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder beside `index.html`, `style.css`, and `script.js`.

## Before publishing
- Add your verified resume as `assets/Aishwarya-Resume.pdf` if you want the Download Resume button to work.
- Add your professional email and LinkedIn URL in the Contact section.
- Add certificates, achievements, and activities only after confirming the details.
- Verify internship dates and status against your records.

## Technologies
HTML, CSS, JavaScript.
